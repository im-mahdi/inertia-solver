# Inertia Solver

Search agent for the Inertia puzzle (BFS / UCS / DFS / DLS / IDS / ILS / A*).

- `v1_tkinter/` - first version (tkinter GUI)
- `v2_pygame/`  - second version (pygame GUI, "Gem Puzzle" look)

Each folder has its own README with run instructions.
Run the commands from inside the folder, e.g. `cd v2_pygame`.
